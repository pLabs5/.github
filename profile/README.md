## pWeb5

a jailbreak autoloader that runs inside the console's browser. it executes the exploit chain in the page, shows you what it is doing while it does it, then pushes homebrew payloads once the chain is up.
live at <https://pweb5.pages.dev>. firmware 7.00 through 13.60.  
*(no firmware other than 13.20 tested fully)*

## dRPC5

a homebrew payload that publishes discord rich presence straight from the console. it connects to the gateway on its own, so there is no PC host or bridge sitting in the middle. it identifies as a console session, so the account shows up as active on PlayStation 5.

## yFree5

a still fairly WIP Native YouTube homebrew app for the PS5 with full Adblock, Sponserblock, Return YouTube Dislike, and more!

## pYTM5

yet to be started, no on-going development yet.

## pLinux5-NG
a new linux loader using the new Bypervisor-reborn HV bug/exploit in order to boot/run linux for higher FW's, 8.xx through 13.xx
